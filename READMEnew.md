Python Practical Assignment

1. Project Description

This project contains three Python programs that demonstrate basic programming concepts, including factorial calculation, Fibonacci series generation, and conversion of C structure data into a Python dictionary.

2. Objectives
	•	To understand basic Python programming.
	•	To calculate the factorial of a number.
	•	To generate the Fibonacci series.
	•	To understand the difference between C structures and Python dictionaries.

3. List of Files
	•	factorial.py – Calculates the factorial of a number.
	•	fibonacci.py – Generates the Fibonacci series.
	•	structure_to_dictionary.py – Represents C structure data using a Python dictionary.

4. Requirements
	•	Python 3.x
	•	Any code editor, such as VS Code or IDLE.
	•	No external libraries required.

5. How to Run the Programs

Open the terminal in your project folder and execute the following commands:

Factorial Prorgram:
python factorial.py

Fibonacci Progranm:
python fibonacci.py

Structure to Dictionary Program:
python structure_to_dictionary.py
